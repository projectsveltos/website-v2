Installing security tools like Wiz across a large fleet of Kubernetes clusters can be a manual and error-prone process. Sveltos simplifies this by providing an automated way to deploy and manage add-ons across multiple clusters.

In this guide, we walk through the steps to:
1.  Set up Sveltos on your management cluster.
2.  Register your AKS clusters.
3.  Define a `ClusterProfile` to deploy the Wiz admission controller.
4.  Verify the installation across all clusters.
